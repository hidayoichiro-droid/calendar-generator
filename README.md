# Buffalo LinuxOS NAS インベントリツール

## 概要
Buffalo LinuxOS NASのフォルダ・ファイル構造を自動的に収集し、Excel形式で出力するPowerShellスクリプトです。

## 主な機能
- ✅ 複数のNASを一括処理（IPアドレスで指定）
- ✅ ドメイン未参加NASに対応（認証情報を明示的に指定）
- ✅ 1台のNAS = 1シート形式でExcel出力
- ✅ サマリー情報（フォルダ数、ファイル数、総容量）を自動集計
- ✅ ツリー構造で詳細を表示
- ✅ 不審なネットワーク活動を回避（適切な接続間隔とリトライ処理）

## 必要要件
- Windows 10/11 または Windows Server 2016以降
- PowerShell 5.1以降
- ImportExcelモジュール（自動インストール可能）
- NASへのアクセス権限を持つアカウント

## セットアップ

### 1. スクリプトのダウンロード
`NAS-Inventory.ps1` をダウンロードして任意のフォルダに保存します。

### 2. 実行ポリシーの設定（初回のみ）
管理者権限でPowerShellを起動し、以下を実行：

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 3. NASリストの編集
スクリプト内の `$NASList` セクションを編集し、対象NASの情報を設定します。

```powershell
$NASList = @(
    @{
        IPAddress = "192.168.1.100"  # NASのIPアドレス
        Name = "NAS01"                # 識別用の名前（Excelシート名に使用）
        SharePath = $null             # 通常はnullのまま（自動検出）
    },
    @{
        IPAddress = "192.168.1.101"
        Name = "NAS02"
        SharePath = $null
    }
)
```

## 使い方

### 基本的な使用方法
```powershell
.\NAS-Inventory.ps1
```

実行すると：
1. ImportExcelモジュールの確認（未インストールの場合は自動インストール）
2. 認証情報の入力を求められます
3. 各NASへ順次接続し、フォルダ・ファイルをスキャン
4. Excelファイルを生成（デフォルト: `NAS-Inventory_yyyyMMdd_HHmmss.xlsx`）

### オプション指定

#### 出力ファイル名を指定
```powershell
.\NAS-Inventory.ps1 -OutputPath "C:\Reports\NAS-Report.xlsx"
```

#### NASごとに異なる認証情報を使用
```powershell
.\NAS-Inventory.ps1 -UseCommonCredential:$false
```

## 出力形式

### Excelファイル構成
各NASごとに1シートが作成され、以下の情報が含まれます：

#### サマリー部分（上部）
| 項目 | 値 |
|------|-----|
| 総フォルダ数 | 1,234 |
| 総ファイル数 | 5,678 |
| 総容量 (GB) | 123.45 |
| 総容量 (Bytes) | 132,547,891,234 |

#### 詳細部分（サマリーの下）

|     file1.pdf | \\192.168.1.100\Share/Documents/file1.pdf | File | 1048576 | 1.00 | 2 |

## トラブルシューティング

### Q1. "ImportExcelモジュールが見つかりません"と表示される
**A:** スクリプトが自動的にインストールを試みますが、失敗する場合は以下を手動実行：
```powershell
Install-Module -Name ImportExcel -Scope CurrentUser -Force
```

### Q2. NASへの接続に失敗する
**A:** 以下を確認してください：
- NASのIPアドレスが正しいか
- 認証情報（ユーザー名/パスワード）が正しいか
- ネットワーク接続が正常か
- ファイアウォールでSMB通信（ポート445）がブロックされていないか

**デバッグ方法：**
```powershell
# NASへの接続テスト
Test-NetConnection -ComputerName 192.168.1.100 -Port 445

# 共有フォルダの確認
net view \\192.168.1.100
```

### Q3. "アクセスが拒否されました"エラー
**A:** 
- NASへのアクセス権限を持つアカウントを使用しているか確認
- 認証情報の入力形式を確認（ドメイン\ユーザー名 または ユーザー名のみ）

### Q4. スキャンが途中で止まる
**A:** 
- 大量のファイルがある場合、数時間かかることがあります
- 進捗表示（1000件ごと）を確認してください
- タイムアウトが発生する場合は、スクリプト内の `$Config.TimeoutSeconds` を増やしてください

### Q5. Excelファイルが開けない
**A:** 
- Excelがインストールされているか確認（閲覧のみであればExcel Viewerでも可）
- ファイルが他のプログラムで開かれていないか確認
- ファイルパスに特殊文字や長いパスが含まれていないか確認

### Q6. "不審なネットワーク活動"として検知される
**A:** スクリプトには以下の対策が組み込まれています：
- NAS間の接続に3秒の待機時間
- 接続失敗時の指数バックオフリトライ（5秒、10秒、20秒...）
- 直列処理（並列接続を避ける）

それでも検知される場合は、`$Config.InterNASDelaySeconds` を5～10秒に増やしてください。

### Q7. 特定のフォルダがスキップされる
**A:** 
- アクセス権限のないフォルダは自動的にスキップされます
- `-Force` オプションで隠しファイルも取得していますが、システムファイルは除外される場合があります

## 設定のカスタマイズ

### スクリプト内の設定パラメータ
```powershell
$Config = @{
    RetryCount = 3                   # 接続リトライ回数
    RetryDelaySeconds = 5            # リトライ間隔（秒）
    InterNASDelaySeconds = 3         # NAS間の待機時間（秒）
    TimeoutSeconds = 300             # タイムアウト（秒）
}
```

### ルートフォルダの手動指定
特定の共有フォルダのみをスキャンしたい場合：
```powershell
$NASList = @(
    @{
        IPAddress = "192.168.1.100"
        Name = "NAS01"
        SharePath = "\\192.168.1.100\Share"  # 特定のパスを指定
    }
)
```

## セキュリティに関する注意事項
- ✅ 認証情報は毎回入力が必要（平文保存を避ける）
- ✅ スクリプト内にパスワードを記述しない
- ⚠️ 本番環境での実行前に必ずテスト環境で動作確認を行ってください
- ⚠️ 出力されたExcelファイルには機密情報が含まれる可能性があるため、適切に管理してください

## パフォーマンスの目安
- 小規模NAS（～10,000ファイル）: 3～5分
- 中規模NAS（～100,000ファイル）: 10～20分
- 大規模NAS（100,000ファイル以上）: 30分～数時間

※ネットワーク速度とNASの性能に依存します

## ライセンス
このスクリプトは自由に使用・改変できます。

## サポート
問題が発生した場合は、以下の情報を添えてお問い合わせください：
- PowerShellのバージョン（`$PSVersionTable.PSVersion`）
- エラーメッセージ全文
- 対象NASの台数とおおよそのファイル数
- ネットワーク構成（VPN経由か、直接接続か、など）
